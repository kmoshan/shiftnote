# 备份、恢复与交接导出专项检查

日期：2026-11-06。检查范围为当前 0.2.1 的数据库备份/恢复、旧备份加密和交接单 Markdown/TXT 导出；所有文件验证使用 UUID 隔离目录，未操作日常数据库。

## 发现并修复

首次跳过口令后，设置页仅显示启用加密面板，“数据库文件”、统计、“立即备份”和“从备份恢复”均被隐藏。原因是数据库信息块的 `v-else-if="stats"` 绑定到了前面的普通模式加密面板，导致只有加密模式能显示备份入口。

改为独立的 `v-if="!loading && stats"`：两种存储模式均在数据库信息加载成功后显示备份与恢复入口，加密面板继续独立显示。新增明文模式确认恢复的 Vue 测试在修复前因找不到恢复按钮失败；修复后通过。浏览器测试分别验证普通和加密模式入口及完整确认流程。

## 页面验证结果

- Vue 组件验证备份提交期间禁止重复提交、成功显示路径、写入失败可重试；普通和加密模式均覆盖。
- 文件选择取消不触发恢复，选择器报错有提示；恢复口令在提交、失败和取消时清空。
- 确认恢复后清理旧事项选择、进展草稿和交接草稿，重新读取处理人、主题、数据库信息与统计，显示恢复前快照路径。
- Edge 浏览器分别执行普通与加密模式的设置页备份、取消选择、错误口令、重试成功和主题刷新；交接预览、定稿、导出取消与确认覆盖的原有浏览器流程也通过。
